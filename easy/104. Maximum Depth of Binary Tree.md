# [104. Maximum Depth of Binary Tree](https://leetcode.com/problems/maximum-depth-of-binary-tree/description/?envType=study-plan-v2&envId=leetcode-75)

## Intuition

The goal of this problem is to find the maximum depth of a binary tree by traversing the paths from the root node to the leaf nodes.

Since a tree is a type of graph without cycles, we can apply both **DFS** and **BFS**, two common graph traversal techniques.

- **DFS** recursively calculates the maximum depth of each subtree and adds `1` for the current node.
- **BFS** traverses the tree level by level and increments the depth by `1` after processing each level.

---

## Approach

### DFS
1. If `root == null`, the subtree does not exist, so return `0`.
2. Otherwise, recursively calculate the maximum depth of the left and right subtrees.
3. Take the larger of the two depths and add `1` for the current node.

### BFS
1. Use a queue to traverse the tree level by level.
2. Process all nodes at the current level.
3. Increment `depth` by `1` after completing each level.
4. Once all nodes have been processed, `depth` represents the maximum depth of the tree.

---

## Complexity
### Time Complexity
`O(n)` — Each node is visited exactly once.

### Space Complexity
- **DFS: O(h)** — The space used by the recursive call stack, where `h` is the height of the tree.
- **BFS: O(w)** — The space used by the queue, where `w` is the maximum width of the tree.

In the worst case, both approaches can require **O(n)** space.

---

## My Solution
### DFS
```
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }

        return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
    }
}
```

### BFS
```
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.add(root);
        int depth = 0;

        while (!queue.isEmpty()) {
            depth++;
            int levelSize = queue.size();

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                
                if (node.left != null) queue.add(node.left);
                if (node.right != null) queue.add(node.right);
            }
        }

        return depth;
    }
}
```


---

## Review

Both approaches are close to optimal in terms of time complexity. Since every node must be visited at least once, both solutions have a time complexity of **O(n)**.

However, DFS and BFS differ in how they calculate depth and how they use additional space.

### Comparison Summary

| Aspect | DFS (Recursive) | BFS (Queue) |
|---|---|---|
| Approach | Traverse down to the leaf nodes, then calculate the depth while returning from the recursive calls | Traverse the tree level by level and calculate the depth one level at a time |
| When depth is calculated | During the return phase of recursive calls (Bottom-up) | After processing each level (Top-down) |
| Time Complexity | O(n) | O(n) |
| Space Complexity | O(h) — Recursive call stack, where `h` is the height of the tree | O(w) — Queue, where `w` is the maximum width of the tree |
| Worst-case space | Can grow to O(n) for a skewed tree | Can grow to O(n) when a large number of nodes exist at the same level |
| Risk of Stack Overflow | Yes — A very deep tree can result in a deeply nested recursive call stack | No — Does not use recursion |
| Code Length / Readability | Short and concise | Slightly longer, but the level-by-level traversal is explicit |
| How depth is represented | Implicitly represented through the recursive call structure | Explicitly represented using the `depth` variable |

For this problem, I prefer DFS because its recursive structure naturally matches the definition of tree depth. The maximum depth of a node is the greater of the depths of its left and right subtrees, plus one for the current node.

BFS is also intuitive because it treats the tree depth as the number of levels. However, since this problem only requires finding the maximum depth, I would choose **DFS for its concise implementation and natural recursive structure.**
