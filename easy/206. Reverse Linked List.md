# [206. Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/description/?envType=study-plan-v2&envId=leetcode-75)

## Intuition

The goal is to reverse the linked list in place without using extra space.

Since each node only stores a reference to the next node, we must save the next node before changing the current node's pointer. We use three pointers (`prev`, `head`, and `temp`) to reverse the list safely in place.

---

## Approach

1. Initialize `prev` as null.
2. Traverse the list while storing the next node in a temporary variable.
3. Reverse the current node's pointer by setting `head.next = prev`.
4. Move both `prev` and `head` one step forward.
5. When the traversal ends, `prev` becomes the new head of the reversed list.

---

## Complexity
### Time Complexity
O(n) — Each node is visited exactly once.

### Space Complexity
O(1) — Only a few pointer variables are used.

---

## My Solution
```
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;

        while (head != null) {
            ListNode temp = head.next;
            head.next = prev;
            prev = head;
            head = temp;
        }

        return prev;
    }
}
```

---

## Review

This is the optimal iterative solution.

- Each node is processed exactly once, resulting in **O(n)** time complexity.
- The reversal is performed in place using only a few pointers, so the space complexity is **O(1)**.
- The key idea is to preserve the next node before changing the current node's pointer, preventing the remaining list from being lost.
