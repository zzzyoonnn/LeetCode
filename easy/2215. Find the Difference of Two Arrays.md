# [2215. Find the Difference of Two Arrays](https://leetcode.com/problems/find-the-difference-of-two-arrays/description/?envType=study-plan-v2&envId=leetcode-75)

## Intuition

After removing duplicate elements, add only the values that do not exist in the other collection to the result list.

---

## Approach

1. Create `list1` to store deduplicated values from `nums1`.
2. Create `list2` to store deduplicated values from `nums2`.
3. Iterate through `list1` and add elements that do not exist in `list2` to the result list.
4. Iterate through `list2` and add elements that do not exist in `list1` to the result list.

---

## Complexity
### Time Complexity
O(n²), nums1, nums2, list1, and list2 are repeatedly traversed.

### Space Complexity
O(n), Additional lists are used to store unique elements and the final result.

---

## My Solution
```
class Solution {
    public List<List<Integer>> findDifference(int[] nums1, int[] nums2) {
        List<Integer> list1 = new ArrayList<>();
        List<Integer> list2 = new ArrayList<>();

        for (int i = 0; i < nums1.length; i++) {
            if (!list1.contains(nums1[i])) list1.add(nums1[i]);
        }

        for (int i = 0; i < nums2.length; i++) {
            if (!list2.contains(nums2[i])) list2.add(nums2[i]);
        }

        List<List<Integer>> answer = new ArrayList<>();
        List<Integer> temp = new LinkedList<>();
        for (int i = 0; i < list1.size(); i++) {
            if (!list2.contains(list1.get(i))) temp.add(list1.get(i));
        }

        answer.add(temp);

        temp = new LinkedList<>();

        for (int i = 0; i < list2.size(); i++) {
            if (!list1.contains(list2.get(i))) temp.add(list2.get(i));
        }

        answer.add(temp);

        return answer;
    }
}
```

---

## Review

The current solution works correctly, but it is inefficient due to `List.contains()` being O(n).<br>

Since the core of this problem is **deduplication +  checking whether an element exists**,<br>
using a `Set` makes the code cleaner and significantly improves time complexity.

- Replace `list1`, `list2` with `Set` → deduplication handled automatically
- Reduce `contains()` cost → overall **O(n)**
- No need for `LinkedList` → `ArrayList` is sufficient
- Shorter code + improved readability

Switching from `List.contains()` (O(n) lookup) to `HashSet.contains()` (O(1) lookup) brings the overall time complexity down from **O(n²) to O(n)**.

## Revised Solution
```
class Solution {
    public List<List<Integer>> findDifference(int[] nums1, int[] nums2) {
        Set<Integer> set1 = new HashSet<>();
        Set<Integer> set2 = new HashSet<>();

        for (int num : nums1) set1.add(num);
        for (int num : nums2) set2.add(num);

        List<Integer> list1 = new ArrayList<>();
        List<Integer> list2 = new ArrayList<>();

        for (int n : set1) if (!set2.contains(n)) list1.add(n);
        for (int n : set2) if (!set1.contains(n)) list2.add(n);

        return List.of(list1, list2);
    }
}
```

### Comparison Summary

| | Before | After |
|---|---|---|
| Deduplication | List + contains | HashSet (handled automatically) |
| Lookup | O(n) | O(1) |
| Overall Complexity | O(n²) | O(n) |
| Code Length | 30 lines | 8 lines |

  - Deduplicated elements implicitly using HashSet instead of manual `contains()` checks on a List
- **Runtime Efficiency**

  - and the percentile ranking improved significantly from **5.00% to 93.25%.**
  - → Replacing `List.contains()` (O(n) per call) with `HashSet.contains()` (O(1) per call) eliminates the repeated linear scans that caused quadratic behavior.
- **Memory Efficiency**
  - Absolute memory usage remained similar at 47.58MB → 47.66MB,
  - and the percentile ranking changed from **38.42% to 22.21%.**
  - → HashSet introduces slightly more memory overhead than ArrayList due to hash table internal structure, resulting in a minor memory tradeoff for the significant runtime gain.
