# [338. Counting Bits](https://leetcode.com/problems/counting-bits/description/?envType=study-plan-v2&envId=leetcode-75)

## Intuition

The goal is to count the number of `1`s in the binary representation of each number.

Instead of converting every number to a binary string, I first wrote down several binary representations to look for a pattern.

| Number | Binary | Number of `1`s |
| ------- | ------- | --------------- |
| 1 | 1 | 1 |
| 2 | 10 | 1 |
| 3 | 11 | 2 |
| 4 | 100 | 1 |
| 5 | 101 | 2 |
| 6 | 110 | 2 |
| 7 | 111 | 3 |

From this, two patterns become apparent.

- The number of `1`s in `i` is equal to the number of `1`s in `i >> 1`, plus `1` if `i` is odd.
- `i & (i - 1)` removes the rightmost `1` bit from `i`.

Using these observations, we can solve the problem with dynamic programming and bit manipulation.

---

## Approach

### Using `i >> 1` (Relationship Between Even and Odd Numbers)

Shifting `i` one bit to the right is equivalent to dividing it by `2`.

- If `i` is even, the last bit is always `0`.
- If `i` is odd, the last bit is always `1`.

Therefore, we can derive the following recurrence relation:

`countBits(i) = countBits(i >> 1) + (i & 1)`

---

### Using `i & (i - 1)`

The expression `i & (i - 1)` removes the rightmost `1` bit from `i`.

For example:
13 = 1101
12 = 1100

1101 & 1100 = 1100

Therefore, we can derive another recurrence relation:

`countBits(i) = countBits(i & (i - 1)) + 1`

---

## Complexity

### Time Complexity

`O(n)` — We iterate through each number only once and reuse previously computed results in `O(1)` time.

### Space Complexity

`O(n)` — We use an array of size `n + 1` to store the results.

---

## My Solution
### Using `i >> 1`
```
class Solution {
    public int[] countBits(int n) {
        int[] ans = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            ans[i] = ans[i >> 1] + (i & 1);
        }

        return ans;
    }
}
```

### Using `i & (i - 1)`
```
class Solution {
    public int[] countBits(int n) {
        int[] ans = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            ans[i] = ans[i & (i - 1)] + 1;
        }

        return ans;
    }
}
```


---

## Review

Both approaches achieve a time complexity of `O(n)` and a space complexity of `O(n)`. They also avoid using `Integer.toBinaryString()` and rely entirely on dynamic programming and bit manipulation.

- **Approach 1** is more intuitive because it leverages the relationship between even and odd numbers.
- **Approach 2** is more concise, but it requires familiarity with the `i & (i - 1)` bit trick.

The `i & (i - 1)` pattern frequently appears in other bit manipulation problems, such as checking whether a number is a power of two. Understanding this technique can be helpful when solving similar problems in the future.
