# [872. Leaf-Similar Trees](https://leetcode.com/problems/leaf-similar-trees/description/?envType=study-plan-v2&envId=leetcode-75)

## Intuition

Two binary trees are **leaf-similar** if their leaf nodes have the **same values in the same left-to-right order.**

Traverse both trees using DFS, collect the leaf values, and compare the two lists.

---

## Approach

1. Traverse both binary trees using **DFS**.
2. Add each leaf node's value to a list.
3. Compare the two lists after both traversals are complete.
4. Return `true` if they are identical; otherwise, return `false`.

---

## Complexity
### Time Complexity
**O(n + m)** — Each node in both trees is visited once.

### Space Complexity
**O(n + m)** — Leaf values are stored in lists, and recursive DFS requires stack space.

---

## My Solution
```
class Solution {
    public boolean leafSimilar(TreeNode root1, TreeNode root2) {
        Deque<Integer> list1 = new ArrayDeque<>();
        Deque<Integer> list2 = new ArrayDeque<>();

        dfs(root1, list1);
        dfs(root2, list2);

        return new ArrayList<>(list1).equals(new ArrayList<>(list2));
    }

    private void dfs(TreeNode root, Deque<Integer> list) {
        if (root == null) return;

        if (root.left == null && root.right == null) {
            list.offer(root.val);
            return;
        }

        dfs(root.left, list);
        dfs(root.right, list);
    }
}
```

---

## Review

The original code stores leaf values in `ArrayDeque` and converts them to `ArrayList` for comparison.

```
return new ArrayList<>(list1).equals(new ArrayList<>(list2));
```

Since only value insertion and list comparison are required, `ArrayList` can be used directly.

This removes unnecessary conversion while keeping the same algorithm.


### Improvement Points

#### ArrayList
- Replace `ArrayDeque` with `ArrayList`.
- Remove unnecessary conversion and copying.
- Keep the same **collect → compare** approach.

#### Stack
- Traverse both trees simultaneously and compare leaf values immediately.
- Return `false` as soon as a mismatch is found.
- Use an explicit Stack instead of recursion to avoid potential `StackOverflowError`.
- No separate list is required to store leaf values.

## Revised Solution

## Ver1. ArrayList
Keeps the original algorithm while replacing `ArrayDeque` with `ArrayList`.
```
class Solution {
    public boolean leafSimilar(TreeNode root1, TreeNode root2) {
        List<Integer> list1 = new ArrayList<>();
        List<Integer> list2 = new ArrayList<>();

        dfs(root1, list1);
        dfs(root2, list2);

        return list1.equals(list2);
    }

    private void dfs(TreeNode root, List<Integer> list) {
        if (root == null) return;

        if (root.left == null && root.right == null) {
            list.add(root.val);
            return;
        }

        dfs(root.left, list);
        dfs(root.right, list);
    }
}
```

## Ver2. Stack
Traverses both trees simultaneously and compares leaf values immediately.
```
class Solution {
    public boolean leafSimilar(TreeNode root1, TreeNode root2) {
        Deque<TreeNode> stack1 = new ArrayDeque<>();
        Deque<TreeNode> stack2 = new ArrayDeque<>();

        if (root1 != null) stack1.push(root1);
        if (root2 != null) stack2.push(root2);

        while (!stack1.isEmpty() && !stack2.isEmpty()) {
            int leaf1 = nextLeaf(stack1);
            int leaf2 = nextLeaf(stack2);

            if (leaf1 != leaf2) return false;
        }

        return stack1.isEmpty() && stack2.isEmpty();
    }

    private int nextLeaf(Deque<TreeNode> stack) {
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();

            if (node.left != null) stack.push(node.left);
            if (node.right != null) stack.push(node.right);

            if (node.left == null && node.right == null) {
                return node.val;
            }
        }

        return -1;
    }
}
```

`right` is pushed first and `left` afterward because the Stack follows **LIFO (Last-In, First-Out)**. Therefore, `left` is popped first, preserving the left-to-right DFS order.

## Performance Comparison



The improvement focuses on **eliminating unnecessary data structure conversion** rather than changing the algorithm.

The `ArrayList` version is the most intuitive in terms of simplicity and readability.

The Stack version supports early termination on mismatch and does not require a separate list for leaf values.

For this problem, the `ArrayList` version is preferred for its **simplicity and readability.**


### Key Improvements (ArrayList Version)
- **Eliminated unnecessary conversion**
  - Use `ArrayList` directly instead of converting `ArrayDeque` before comparison.
  - → Removes unnecessary copying and conversion.
- **Simplified data structure usage**
  - `ArrayDeque` was only used to store leaf values.
  - `ArrayList` better matches the required operations.
  - → Simpler code structure.
- **Improved execution efficiency**
  - Time complexity remains **O(n + m)**.
  - Unnecessary copying during conversion is eliminated.
  - → Same algorithmic complexity with fewer operations.
- **Improved readability**
  - Removes the intermediate conversion step.
  - → Clearer intent: **collect leaf values → compare the lists**.
