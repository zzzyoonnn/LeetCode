# [1456. Maximum Number of Vowels in a Substring of Given Length](https://leetcode.com/problems/maximum-number-of-vowels-in-a-substring-of-given-length/description/?envType=study-plan-v2&envId=leetcode-75)

## Intuition

We need to find the maximum number of vowels among all substrings of length `k`.

A brute-force approach checks every substring of length `k` and counts its vowels from scratch.

---

## Approach

1. Convert `s` into a character array.
2. Move a window of length `k` from left to right, one position at a time.
3. For each window, check all `k` characters and count the number of vowels.
4. Keep track of the maximum number of vowels found so far.

---

## Complexity
### Time Complexity
**O(n × k)** — There are `n - k + 1` possible windows, and each window checks `k` characters to count the vowels.

### Space Complexity
**O(n)** — Additional space is required to create a character array using `s.toCharArray()`.

---

## My Solution
```
class Solution {
    public int maxVowels(String s, int k) {
        char[] arr = s.toCharArray();

        int count = 0, maxCount = 0;
        for (int i = 0; i < arr.length - k + 1; i++) {
            count = 0;

            for (int j = 0; j < k; j++) {
                if (arr[i + j] == 'a' || arr[i + j] == 'e' || arr[i + j] == 'i' || arr[i + j] == 'o' || arr[i + j] == 'u') count++;
            }

            maxCount = Math.max(maxCount, count);
        }

        return maxCount;
    }
}
```

---

## Review

This implementation counts the vowels from scratch using an inner for loop for every window, resulting in **O(n × k)** time complexity.

When I submitted it, it resulted in a **Time Limit Exceeded (TLE)** error for large inputs where both the string length and `k` were large. It passed 103 out of 107 test cases.



The key problem is that consecutive windows overlap. Instead of recounting all `k` characters every time the window moves, we can reuse the vowel count from the previous window.

By incrementally updating the vowel count, we can reduce the time complexity from **O(n × k)** to **O(n)**.

---

## Revised Solution
```
class Solution {
    public int maxVowels(String s, int k) {
        char[] arr = s.toCharArray();
        int count = 0, maxCount = 0;
        
        for (int i = 0; i < k; i++) {
            if (isVowel(arr[i])) count++;
        }
        maxCount = count;

        for (int i = k; i < arr.length; i++) {
            if (isVowel(arr[i])) count++;
            if (isVowel(arr[i - k])) count--;

            maxCount = Math.max(maxCount, count);
        }

        return maxCount;
    }

    private boolean isVowel(char c) {
        return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';
    }
}
```

### Comparison Summary
| | Before | After |
|---|---|---|
| **Time Complexity** | O(n × k) | O(n) |
| **Core Idea** | Recount the vowels from scratch for each window | Incrementally update the vowel count using the previous window |
| **Window Movement** | Recheck all `k` characters | Check only the character entering and leaving the window |
| **Handling Overlapping Regions** | Does not reuse previous calculations | Reuses the previous window's vowel count |
| **Space Complexity** | O(n) | O(n) |

---

## Performance Comparison

The revised solution using the sliding window technique eliminates the repeated work performed by the original brute-force approach.

### Key Improvements
- **Reuse the previous window's result**
  - The original solution checks all `k` characters from scratch every time the window moves one position.
  - The improved solution updates the count by adding the newly entering character (+1) and removing the character leaving the window (-1).
  - This reduces the time complexity from **O(n × k)** to **O(n)**.
- **Resolved TLE**
  - The original solution resulted in a **Time Limit Exceeded** error when both the string length and `k` were large.
  - After switching to the sliding window approach, the solution passed all test cases within the time limit.
- **The space complexity remains the same**
  - Both solutions create a character array using `s.toCharArray()`, resulting in **O(n)** additional space.
  - In other words, this optimization improves the time complexity without increasing the additional space complexity.
