# [151. Reverse Words in a String](https://leetcode.com/problems/reverse-words-in-a-string/description/?envType=study-plan-v2&envId=leetcode-75)

## Intuition

Split the string into words based on whitespace, then concatenate the words in reverse order by iterating from the end.

---

## Approach

1. Split the string into individual words based on whitespace.
2. Iterate through the array of words from the end and append each word to a `StringBuilder`.
3. Add a single space between words.
4. Return the resulting string.

---

## Complexity
### Time Complexity
**O(n)** — Iterate through the words from the end and process each character once.

### Space Complexity
**O(n)** — Additional space is required to store the split tokens and the resulting string.

---

## My Solution
```
import java.util.*;

class Solution {
    public String reverseWords(String s) {
        StringTokenizer st = new StringTokenizer(s);

        String token;
        StringBuilder sb = new StringBuilder();
        while (st.hasMoreTokens()) {
            token = st.nextToken();

            if (!sb.isEmpty()) sb.insert(0, " ");
            sb.insert(0, token);
        }

        return sb.toString();
    }
}
```

---

## Review

The main issue with the original solution is inserting strings at the beginning of the `StringBuilder` using `insert(0, ...)`.

When a string is inserted at the beginning of a `StringBuilder`, the existing characters need to be shifted. Repeating this operation can result in **O(n²)** time complexity in the worst case.

`StringTokenizer` is an older class, but it is still supported and works correctly for this problem. However, `String.split()` is generally more common in modern Java code.

### Improvements
- Use `s.trim()` to remove leading and trailing whitespace.
- Use `split("\\s+")` to split the string based on consecutive whitespace.
- Iterate through the array from the end.
- Append each word to the end of the `StringBuilder`.


---

## Revised Solution
```
class Solution {
    public String reverseWords(String s) {
        String[] tokens = s.trim().split("\\s+");

        StringBuilder sb = new StringBuilder();
        for (int i = tokens.length - 1; i >= 0; i--) {
            sb.append(tokens[i]);
            if (i > 0) sb.append(" ");
        }

        return sb.toString();
    }
}
```

Therefore, the key improvement was **not replacing `StringTokenizer` with `split()`**, but rather **removing `insert(0, ...)` and using `append()` instead**.


### Key Improvements

- **Replace `insert(0, ...)` with `append()`**
  - The original solution inserts strings at the beginning of the `StringBuilder`, which can result in **O(n²)** time complexity due to repeatedly shifting existing characters.
  - The revised solution iterates through the words from the end and uses `append()` to build the result.
  - This improves the time complexity from **O(n²) to O(n)**.
- **Change the Tokenization Method to `split("\\s+")`**
  - The revised solution uses `split("\\s+")` instead of `StringTokenizer` to split the string based on consecutive whitespace.
  - This makes the code more straightforward and is a commonly used approach in modern Java.
  - However, `StringTokenizer` may use less memory in this particular problem.
