# [1657. Determine if Two Strings Are Close](https://leetcode.com/problems/determine-if-two-strings-are-close/description/?envType=study-plan-v2&envId=leetcode-75)

## Intuition

Operation 1 swaps the positions of characters, while Operation 2 swaps the frequencies of two characters.

Therefore, for two strings to be close, they must satisfy the following conditions:

- They contain the same set of characters.
- Their character frequencies are identical when sorted.

To check this, we store the frequency of each character in an array of size 26. Since the input is limited to lowercase English letters, we use an array instead of a HashMap, avoiding the overhead of an additional data structure.

---

## Approach

1. Return `false` if the two strings have different lengths.
2. Count the frequency of each character in both strings.
3. Check whether both strings contain the same set of characters.
4. Sort both frequency arrays and compare them.

---

## Complexity
### Time Complexity
**O(n)** — Counting character frequencies takes `O(n)`, and sorting the arrays takes `O(26 log 26)`, which is constant time.

### Space Complexity
**O(n)** — Use two arrays of size 26.

---

## My Solution
```
class Solution {
    public boolean closeStrings(String word1, String word2) {
        if (word1.length() != word2.length()) return false;

        int[] freq1 = new int[26];
        int[] freq2 = new int[26];

        for (char c : word1.toCharArray()) freq1[c - 'a']++;
        for (char c : word2.toCharArray()) freq2[c - 'a']++;

        for (int i = 0; i < 26; i++) {
            if ((freq1[i] == 0) != (freq2[i] == 0)) return false;
        }

        Arrays.sort(freq1);
        Arrays.sort(freq2);

        return Arrays.equals(freq1, freq2);
    }
}
```
