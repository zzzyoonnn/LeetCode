# [238. Product of Array Except Self](https://leetcode.com/problems/product-of-array-except-self/description/?envType=study-plan-v2&envId=leetcode-75)

## Intuition

We need to return an array where each element is the product of every element in `nums` except itself.

Since division is not allowed and the array may contain `0`, we can solve this problem in `O(n)` time by using prefix products from both the left and right sides.

---

## Approach

1. Create a left prefix product array.
   - `left[i]` stores the product of all elements to the left of `nums[i]`.
2. Create a right prefix product array.
   - `right[i]` stores the product of all elements to the right of `nums[i]`.
3. Calculate the result using `answer[i] = left[i] * right[i]`.

---

## Complexity
### Time Complexity
**O(n)** - where n is the length of the array

### Space Complexity
**O(n)** - where n is the length of the array

---

## My Solution
```
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int size = nums.length;
        int[] left = new int[size];
        int[] right = new int[size];

        left[0] = right[size - 1] = 1;

        for (int i = 1; i < size; i++) {
            left[i] = left[i - 1] * nums[i - 1];
        }

        for (int i = size - 2; i >= 0; i--) {
            right[i] = right[i + 1] * nums[i + 1];
        }

        int[] answer = new int[size];
        for (int i = 0; i < size; i++) {
            answer[i] = left[i] * right[i];
        }

        return answer;
    }
}
```

---

## Review

The prefix product logic using the `left` and `right` arrays is implemented correctly. The solution also handles edge cases such as `0` and negative numbers without any issues. The time complexity is `O(n)`, and there are no logical errors.

However, the solution uses three `O(n)` arrays: `left`, `right`, and `answer`. We can further optimize the space complexity by eliminating the `left` and `right` arrays.

By doing so, we can reduce the **auxiliary space complexity to `O(1)`**, excluding the output array.

---

## Revised Solution
```
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int size = nums.length;
        int[] answer = new int[size];

        answer[0] = 1;
        for (int i = 1; i < size; i++) {
            answer[i] = answer[i - 1] * nums[i - 1];
        }

        int rightProduct = 1;
        for (int i = size - 1; i >= 0; i--) {
            answer[i] *= rightProduct;
            rightProduct *= nums[i];
        }

        return answer;
    }
}
```
