# [746. Min Cost Climbing Stairs](https://leetcode.com/problems/min-cost-climbing-stairs/description/?envType=study-plan-v2&envId=leetcode-75)

## Intuition

We need to find the minimum cost to reach the top by moving either one or two steps at a time.

Since the same index can be visited multiple times, we can use **memoization** to store and reuse the minimum cost already calculated for each index.

---

## Approach

1. Use a memo array to store the minimum cost for each index.
2. Recursively move one or two steps and reuse previously calculated values.
3. Return the smaller cost of starting from index 0 or 1.

---

## Complexity

### Time Complexity

**O(n)** — With memoization, the minimum cost for each index is calculated only once.

### Space Complexity

**O(n)** — Both the `memo` array and the recursive call stack can use up to O(n) space.

---

## My Solution

```
import java.util.*;

class Solution {
  private static int[] memo;

  public int minCostClimbingStairs(int[] cost) {
    memo = new int[cost.length];
    Arrays.fill(memo, -1);

    return Math.min(climb(cost, 0), climb(cost, 1));
  }

  private static int climb(int[] cost, int index) {
    if (index >= cost.length) return 0;
    if (memo[index] != -1) return memo[index];

    int result = cost[index] + Math.min(
        climb(cost, index + 1),
        climb(cost, index + 2)
    );

    memo[index] = result;
    return result;
  }
}
```

---

## Review

Memoization achieves **O(n)** time complexity by reusing previously calculated values.

However, each state only depends on the previous two states, so the `memo` array and recursive call stack can be eliminated by using an iterative approach with two variables. This reduces the space complexity from **O(n) to O(1)**.

### Improvements

- Recursion (Top-down) → Iteration (Bottom-up)
- `memo` array + call stack → Two variables (`prev1`, `prev2`)
- Space Complexity: **O(n) → O(1)**

---

## Revised Solution

```
class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int n = cost.length;
        int prev2 = 0, prev1 = 0;

        for (int i = 2; i <= n; i++) {
            int cur = Math.min(
                prev1 + cost[i - 1],
                prev2 + cost[i - 2]
            );

            prev2 = prev1;
            prev1 = cur;
        }

        return prev1;
    }
}
```

---

## Comparison Summary

|                     | Memoization (Top-down) | Iteration (Bottom-up) |
| ------------------- | ---------------------- | --------------------- |
| Time                | O(n)                   | O(n)                  |
| Space               | O(n)                   | O(1)                  |
| Function calls      | Recursive calls        | None                  |
| Stack overflow risk | Possible               | None                  |

### Key Improvements

**1. Recursion → Iteration**

The recursive calls were replaced with an iterative approach, eliminating function call overhead and the recursive call stack.

**2. Array → Two Variables**

The current minimum cost only depends on the previous two states, so the entire `memo` array can be replaced with two variables, `prev1` and `prev2`.

**3. Space Complexity**

- Original: **O(n)**
- Revised: **O(1)**

Both approaches have the same **O(n)** time complexity, but the iterative solution eliminates the unnecessary array and recursive call stack, reducing the additional space complexity from **O(n) to O(1)**.
